Panduan Integrasi CI/CD & REST API

Integrasikan pipeline GitHub Actions / GitLab CI untuk mengunggah binary secara otomatis setiap kali rilis baru dibuat.

1. Streaming Upload via HTTP PUT (Direkomendasikan untuk CI/CD) 
curl -T build/METDesk-2.3.1.dmg \
  "https://metdesk-update-server-dev.hasdev.workers.dev/storage/METDesk-2.3.1.dmg?update_release=true&platform=macos" \
  -H "X-API-Key: YOUR_UPLOAD_AUTH_KEY"

Gunakan parameter update_release=true agar binary otomatis terpasang ke release.json aktif.

2. Upload via Multipart Form (HTTP POST) 
curl -X POST \
  -F "file=@build/METDesk-2.3.1.dmg" \
  "https://metdesk-update-server-dev.hasdev.workers.dev/storage?update_release=true&platform=macos" \
  -H "X-API-Key: YOUR_UPLOAD_AUTH_KEY"
3. Contoh Workflow GitHub Actions 
name: Publish METDesk Update
on:
  push:
    tags: ['v*']

jobs:
  upload:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - name: Upload Binary to Update Server
        run: |
          curl -T "dist/METDesk-${{ github.ref_name }}.dmg" \
            "${{ secrets.UPDATE_SERVER_URL }}/storage/METDesk-${{ github.ref_name }}.dmg?update_release=true&platform=macos" \
            -H "X-API-Key: ${{ secrets.UPLOAD_AUTH_KEY }}"
4. Referensi REST API Endpoint
Method Endpoint Deskripsi Auth
GET /updates Ambil metadata rilis aktif (.dmg / .exe URLs, sha256, changelog) Public
GET /storage/:filename Download installer (Mendukung HTTP 206 Range requests / resume) Public
PUT /storage/:filename Streaming upload binary installer langsung ke Cloudflare R2 / Disk X-API-Key
POST /api/storage/set-active Pilih binary yang sudah ada sebagai versi rilis aktif untuk platform tertentu Session / Key
DELETE /storage/:filename Hapus file binary installer dari storage Session / Key
